# Vega-Lite Gallery

A small data visualisation project created to practise building and embedding interactive charts using Vega-Lite.

## What I Did

- Created multiple visualisations using Vega-Lite
- Built chart specifications using separate `.vg.json` files
- Embedded Vega-Lite visualisations into an HTML webpage
- Added multiple charts to the same page
- Added chart labels, tooltips and interactions
- Created a responsive side-by-side gallery layout using CSS
- Styled the webpage and visualisation cards
- Published the project using GitHub Pages

## Visualisations

- Daily Spending by Category — bar chart
- Study Time and Score — scatter plot
